# The Little Taco Shop

A responsive multi-page HTML and CSS practice website inspired by the freeCodeCamp HTML tutorial.

## Pages
- `index.html`: Home, About, Menu table
- `hours.html`: Store opening hours
- `contact.html`: Contact form and address

## Concepts practised
HTML document structure, metadata, headings, paragraphs, links, navigation, semantic sections, details/summary, tables, forms, labels, input types, textarea, buttons, and telephone links.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Vercel
Import this GitHub repository into Vercel. It is a static site, so no build command is needed.
